# Decision records

One file per decision, numbered, in the form `NNNN-short-title.md`. A record is never
edited after it is accepted. If a decision changes, a new record supersedes it and says so.

Each record has four parts:

1. **Context.** What forced the decision and what was known at the time.
2. **Options.** The alternatives considered, each with its trade-off.
3. **Decision.** The option chosen and why.
4. **Consequences.** What becomes easier, what becomes harder, what must be revisited.

Records are written when a decision is made, not at the end. The commit date is the
decision date.
